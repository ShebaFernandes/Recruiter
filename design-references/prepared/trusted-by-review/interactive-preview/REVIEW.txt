The query opt-in works only on loopback hosts in Vite development mode.
Production removes the lazy component import and its source artwork. It is
not sufficient to add the query to a deployed URL. No environment secrets,
backend changes, permission grants, or public publication are involved.

The preview adds one moving row directly after the unchanged mountain hero.
No company cards or name grid. Original logo colors/proportions are retained.
There is no visible preview toolbar or public relationship heading.
All ten public-display permissions and the final heading remain pending.

Hover or keyboard focus opens a company detail popup rendered outside the
clipping strip. Escape/outside tap dismiss; tap again toggles. Keyboard mode
uses a stationary horizontally scrollable row so every company remains
reachable. Reduced motion also uses the single stationary scrollable row.
A Pause/Resume button is available to screen readers and becomes visible on
keyboard focus, without reserving a toolbar row in the layout.
Desktop 20px/second, mobile 20px/second, identical repeated sequences.
The preview pauses offscreen and when the browser document is hidden.

Source artwork: ../assets; no logos copied into frontend/public.
Navadhan uses the prepared source PNG in this development-only preview;
optimize its delivery before any separately approved public implementation.
