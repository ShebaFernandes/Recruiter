3. IMPLEMENTATION
New read-only employment_history.py evaluates the latest upload (including failure
and pending processing), its accepted evidence, and the CURRENT saved records.
It compares row contents, dates, current flags, employment type and details using
the existing reconciliation comparison, not equal counts or company names alone.
Only accepted pipeline rows with evidence and supported/partial confidence qualify.
The API returns current verified_role_ids, candidate_confirmed_role_ids and
unverified_role_ids with latest resume ID/state and extraction source. It exposes
this same safe classification to authorized candidate/recruiter views, without raw
resume text, evidence excerpts, consent details or provider responses.
No historical candidate rows or extraction snapshots were migrated or rewritten.

The shared CareerJourney draws only saved IDs verified against the latest upload.
When there is no uploaded resume, clearly candidate-confirmed/manual records may
form a labelled candidate-confirmed timeline. Legacy rows without provenance are
retained for review rather than silently certified.
Unmatched saved records appear in a closed-by-default review disclosure, with full
employer, title, month/year dates and explicit candidate-confirmed/manual versus
older-record labels. A zero-role/failed extraction shows review needed and no
fabricated primary graph. Explicit no-employment statements remain distinct.
Candidate can use Review saved profile; edits are retained through the existing UI.
The latest local upload now reports 0 verified IDs, 7 retained IDs, 7 confirmed/manual
IDs. These seven records remain safely stored and are not presented as new extraction.

The existing continuous horizontal date-scaled timeline, internship evidence rule,
stronger full-time colors, overlap lanes, promotions, single-role sizing, incomplete
dates and mobile scrolling remain shared. Fixed false gaps between consecutive
months (e.g. Dec -> Jan promotion). Removed old opacity reduction so review text
stays readable. Full employer names/titles/dates remain visible; no ellipsis added.
